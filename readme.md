# 中大日影－校園避曬地圖

計算機概論期末專題｜第十二組

## 專題動機

中央大學的校園很大，平常上下課時常常需要在不同的教學大樓之間移動，尤其夏天走在沒有遮蔽物的路上真的很熱。

因此，我們想做一個可以根據不同日期及時間，模擬校園建築物陰影的地圖，並結合路徑規劃，讓使用者除了找到最短路線，也可以選擇曬到較少太陽的路線。

## 功能介紹

- 選擇日期及時間，查看校園建築物的陰影變化。
- 查詢指定位置是否位於陰影內。
- 查看未來 30 分鐘的陰影變化。
- 自行選擇起點及終點。
- 比較最短路線與避曬路線。
- 調整避曬偏好，查看不同的路徑規劃結果。
- 比較步行距離、預估時間及遮蔭比例。

## 程式設計

本專題主要使用 C、C++ 及 Python 完成。

| 語言 | 用途 |
|---|---|
| C | 讀取及儲存建築物資料 |
| C++ | 計算太陽位置、建築物陰影及最佳路徑 |
| Python | 處理地圖資料、串接程式 |
| HTML、CSS、JavaScript | 網頁介面及地圖互動 |

建築物與道路資料取自 OpenStreetMap，根據日期、時間及中央大學的經緯度計算太陽高度角與方位角，再利用建築物高度推算陰影範圍。

路徑規劃部分使用 Dijkstra 演算法，除了道路長度之外，也將道路上的日照距離納入權重計算。

## 使用方式

下載專案後，解壓縮並開啟 `index.html` 即可使用。

也可以透過 Python 執行 `python run.py`，再開啟 http://127.0.0.1:8000。

## 目前限制

- 部分建築物缺少實際高度資料，因此暫時使用估計值。
- 目前主要計算建築物的陰影，尚未考慮樹木、天氣及地形。
- 路徑規劃以出發時間的陰影分布為基準。
- 陰影模擬結果尚未經過實地量測驗證。
