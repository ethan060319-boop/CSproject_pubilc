# 中大日影－校園避曬地圖

計算機概論期末專題｜第十二組

## 專題動機

中央大學的校園很大，平常上下課時常常需要在不同的教學大樓之間移動，尤其夏天走在沒有遮蔽物的路上真的很熱。

因此，我們想做一個可以根據不同日期及時間，模擬校園建築物陰影的地圖，並結合路徑規劃，讓使用者除了找到最短路線，也可以選擇曬到較少太陽的路線。

## 功能介紹

- 選擇日期及時間，查看校園建築物的陰影變化。
- 點校園內任何一棟建築，查看它東、南、西、北四側一天中哪些時段有陰影、共幾小時。
- 點空地，查看該位置的全天遮蔭時段，以及所選時刻與 30 分鐘後的狀態。
- 自行選擇起點及終點。
- 比較最短路線與避曬路線。
- 調整避曬偏好，查看不同的路徑規劃結果。
- 比較步行距離、預估時間及遮蔭比例。

## 程式設計

本專題主要使用 C、C++ 及 Python 完成。

| 語言 | 用途 |
|---|---|
| C | 讀取及儲存建築物資料 |
| C++ | 計算太陽位置、建築物陰影及最佳路徑 |
| Python | 處理地圖資料、串接程式 |
| HTML、CSS、JavaScript | 網頁介面及地圖互動 |

建築物與道路資料取自 OpenStreetMap，根據日期、時間及中央大學的經緯度計算太陽高度角與方位角，再利用建築物高度推算陰影範圍。

路徑規劃部分使用 Dijkstra 演算法，除了道路長度之外，也將道路上的日照距離納入權重計算。

## 使用方式

下載專案後，解壓縮並開啟 `index.html` 即可使用。修改 `web/`、`shade/` 或高度表後，執行 `python build.py` 重新產生 `index.html`。

也可以透過 Python 執行 `python run.py`，再開啟 http://127.0.0.1:8000。

## 目前限制

- 部分建築物缺少實際高度資料，因此暫時使用估計值。
- 目前主要計算建築物的陰影，尚未考慮樹木、天氣及地形。
- 路徑規劃以出發時間的陰影分布為基準。
- 步行路網取自 OSM。校內道路常被標成 `access=private`，本專案視為師生可步行；OSM 中沒有接上、相距 20 公尺內的路段會自動補接線，路段擦進建築輪廓 2 公尺以內也視為誤差保留。仍接不上的零星路段不納入路網。
- 陰影模擬結果尚未經過實地量測驗證。

## 建築物高度

建築輪廓取自 OpenStreetMap，但 111 棟建築中只有 4 棟有樓層資料，因此另外整理了校方公開的樓層數。高度依下列順序決定：

1. `building_heights.csv` 中的資料（`height_m` 優先，其次 `levels` × 3.5 m）。其中 48 棟的樓層數取自[中大防災中心 109 年〈校園災害潛勢評估報告〉](https://military.ncu.edu.tw/CSRC/download/%E9%99%84%E4%BB%B6%E4%B8%80%E6%A0%A1%E5%9C%92%E7%81%BD%E5%AE%B3%E6%BD%9B%E5%8B%A2%E8%A9%95%E4%BC%B0%E5%A0%B1%E5%91%8A(109%E5%B9%B4).pdf)附件一的耐震評估清冊（`data_source` 欄為 `ncu_report`，`note` 欄記有清冊項次）；`note` 標「推測對應」的幾棟是名稱不完全相同、由我們判斷的對應。
2. OSM 的 `height`。
3. OSM 的 `building:levels` × 3.5 m。
4. 都沒有時依面積估計：面積小於 150 m² 或車庫等附屬建物 3.5 m；未命名且小於 400 m² 或住宅 7 m；其餘暫用 12 m。
